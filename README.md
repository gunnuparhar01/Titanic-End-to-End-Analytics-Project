# Titanic-End-to-End-Analytics-Project
End-to-End Data Analytics Project using Python, SQL, Power BI and Machine Learning.

## Project Overview

This project analyzes the Titanic dataset to identify factors influencing passenger survival and builds a machine learning model to predict survival.

---

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- SQL
- Power BI
- Scikit-learn
- Joblib

---

## Project Workflow

1. Data Cleaning
2. Exploratory Data Analysis (EDA)
3. Feature Engineering
4. SQL Business Queries
5. Power BI Dashboard
6. Machine Learning Models
7. Model Evaluation

---

## Machine Learning Models

- Logistic Regression
- Decision Tree
- Random Forest

---

## Power BI Dashboard Features

- KPI Cards
- Interactive Slicers
- Survival Analysis
- Key Influencers
- AI Insights

---

## Key Business Insights

- Female passengers had a significantly higher survival rate.
- First-class passengers were more likely to survive.
- Higher fare passengers generally had better survival outcomes.
- Family size influenced survival probability.
- Gender was the most important feature in the Random Forest model.
